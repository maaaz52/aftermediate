aftermediate — Complete Feature List

What it is: An AI-driven career counseling and university planning platform built specifically for Pakistani students who just finished FSc, ICS, I.Com, or A-Level.

Website: www.aftermediate.site

Status: Live, deployed, production-ready

1. ONBOARDING & PERSONALIZATION

  • Smart onboarding quiz — asks stream (Pre-Med, Pre-Eng, ICS, I.Com), marks, interests, budget, preferred city, and career priorities
  • OCR marksheet scan — upload a photo of your FSc/A-Level marksheet and the AI reads your subjects and grades automatically (no typing needed)
  • Onboarding powers every page — the entire app adapts based on your answers (recommendations, merit calculations, AI responses all personalized)
  • Re-take onboarding anytime — if marks or preferences change, retake the quiz and everything updates
  • Custom avatar — choose from 10 dicebear avatar styles with a custom seed
  • Profile page — edit name, email, education, skills, avatar; all changes save instantly
  • Education lock — once you set your board and stream, it's locked (prevents accidental changes that break merit calculations)
  • Skills search — add skills from a searchable list or type custom ones
  • Save toast — profile edits show a confirmation toast
  • Data deletion — delete your entire account and all data from the profile page

2. DASHBOARD

20. SECURITY

  • OTP email verification — 6-digit code for sign-up (not magic links)
  • Constant-time OTP comparison — prevents timing attacks
  • OTP code hashing — SHA-256 hashed before storage (plaintext never stored)
  • Code burning — OTP can only be used once
  • Rate limiting on OTP — max 5 attempts per code, max 3 sends per IP per hour
  • Session revocation on password change — all other sessions killed via GoTrue admin API
  • Secure cookies — SameSite=Lax, Secure in production
  • Enumeration-safe errors — same error message for "wrong code" and "expired code"
  • HSTS — max-age=63072000; includeSubDomains (forces HTTPS for 2 years)
  • CSP headers — Content Security Policy prevents XSS attacks
  • X-Frame-Options — prevents clickjacking
  • X-Content-Type-Options — prevents MIME sniffing
  • Referrer-Policy — controls how much referrer info is shared
  • Permissions-Policy — camera, microphone, geolocation disabled
  • Row-Level Security (RLS) — users can only access their own data in the database
  • SECURITY DEFINER functions — database functions run with elevated privileges, not the calling user
  • Least-privilege API role — the API database role can only do what's explicitly allowed
  • Security event logging — authentication events logged for audit
  • OCR body cap — 4.5MB limit on marksheet uploads (matches Vercel's limit)
  • Service-role key — only used server-side, never exposed to client
  • R2 video key allowlist — only pre-approved video keys can be signed
  • Self-XSS prevention — chat PDF export and resume links sanitized
  • Watchlist notify rate limit — server-side cooldown prevents email spam
